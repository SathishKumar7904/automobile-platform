# 13 — MVP Priority

## P0 — Must Have

These features define the MVP:

1. Authentication
2. Role-based authorization
3. Vehicle catalog
4. Vehicle search
5. Vehicle details
6. Variant selection
7. Dealer discovery
8. Dealer selection
9. Customer enquiry
10. Lead creation
11. Dealer lead dashboard
12. Lead details
13. Lead status updates
14. Dealer notes
15. Customer enquiry tracking
16. Basic admin management
17. Data validation
18. Error handling
19. Persistent database storage

## P1 — Important but Non-Blocking

1. Basic inventory management
2. Basic notifications
3. Test-drive request
4. Better search/filtering
5. Basic analytics
6. Improved audit visibility

## P2 — Future

1. Quotation engine
2. Booking
3. Payments
4. Finance
5. Insurance
6. Registration
7. Vehicle allocation
8. PDI
9. Delivery scheduling
10. After-sales
11. Advanced recommendations
12. Real-time chat
13. External ERP/DMS integrations

## 4. Priority Rule

If a P1 feature threatens the stability of the P0 customer-to-dealer lead flow, defer the P1 feature.

The MVP must optimize for a working business loop, not feature count.

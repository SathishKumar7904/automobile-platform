# 03 — Customer Journey

## 1. Customer Goal

Find a suitable vehicle and connect with an appropriate dealer with minimum friction.

## 2. Journey

### Stage 1 — Discover
Customer opens the platform and browses/searches vehicles.

### Stage 2 — Filter
Customer can narrow results using core attributes such as:
- Brand
- Model
- Body type
- Fuel type
- Transmission
- Price range

### Stage 3 — Evaluate
Customer opens vehicle details and reviews:
- Vehicle information
- Specifications
- Features
- Price
- Variants
- Basic availability
- Dealers

### Stage 4 — Configure
Customer selects a variant and relevant configuration supported by the MVP.

### Stage 5 — Dealer Selection
Customer sees eligible/available dealers and chooses one.

### Stage 6 — Enquiry
Customer submits:
- Name
- Contact information
- Selected vehicle
- Selected variant
- Dealer
- Message
- Preferred contact method where supported

### Stage 7 — Confirmation
Customer receives an enquiry confirmation and enquiry identifier.

### Stage 8 — Tracking
Customer opens "My Enquiries" and sees:
- Vehicle
- Dealer
- Current status
- Last updated information
- Status timeline

## 3. Customer Experience Principles

- Search should be fast and understandable.
- Vehicle information must be structured.
- Dealer choice must be explicit.
- Enquiry submission must clearly confirm success.
- Customers must never be left wondering whether their request reached a dealer.
- Status changes must be understandable.
- Validation and error messages must be actionable.

## 4. Customer Journey State

```text
DISCOVER
  ↓
EVALUATE
  ↓
SELECT
  ↓
ENQUIRE
  ↓
TRACK
```

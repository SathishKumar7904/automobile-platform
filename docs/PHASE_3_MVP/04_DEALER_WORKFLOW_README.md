# 04 — Dealer Workflow

## 1. Dealer Goal

Convert platform-generated customer interest into real sales opportunities.

## 2. Dealer Lifecycle

```text
Dealer Login
  ↓
Dashboard
  ↓
New Lead
  ↓
Review Lead
  ↓
Contact Customer
  ↓
Update Status
  ↓
Follow-up / Interest / Conversion
```

## 3. Dealer Dashboard

Minimum information:
- New leads
- Contacted leads
- Follow-up leads
- Interested leads
- Converted leads
- Closed leads

## 4. Lead Details

Dealer should see:
- Lead ID
- Customer name
- Customer contact information permitted by policy
- Vehicle
- Variant
- Customer message
- Created timestamp
- Current status
- Lead history
- Internal notes

## 5. Dealer Actions

- Open lead
- Mark contacted
- Mark interested
- Schedule follow-up
- Add note
- Close lead
- Mark converted where appropriate

## 6. Inventory

Basic MVP inventory may allow a dealer to record:
- Vehicle/variant
- Color
- Quantity/status
- Basic availability

This is not a manufacturer ERP or dealership DMS integration.

## 7. Dealer Operational Boundary

The dealer may perform activities outside the application:
- Phone calls
- Physical test drives
- In-person negotiations
- Physical document verification
- Final dealership processes

The application records the relevant business state rather than attempting to replace all dealership operations.
